# Burrows Applications

**Software, built with care.**

Burrows Applications specializes in mobile-first development — native apps for Android and iOS, Kotlin Multiplatform for cross-platform, and modern websites when your product needs a home on the web.

Specialties: native mobile · cross-platform · web

## Mobile and web development services.

Start from what you have: an app on one platform, an aging codebase, an idea, or a site that needs building.

### iOS to Android and Android to iOS migration

Bring an Android app to iOS, or an iOS app to Android, as a native app that keeps the features and behavior its users already know.

### Kotlin Multiplatform (KMP) development

Share business logic, networking, and storage between Android and iOS with Kotlin Multiplatform, adopted one module at a time or from the start.

### Native Android and iOS apps

New native apps for Android and iOS, built for each platform from the first screen to release.

### Custom websites built from scratch

Modern websites built from a blank page, fast and accessible, for a product that needs a home on the web.

### Mobile app and website security analysis

A review of a mobile app or website for security weaknesses, from how data is stored and sent to dependencies and server headers, with a written list of findings and fixes.

### Java to Kotlin migration and modernization

Bring an aging codebase up to date: Java to Kotlin, outdated libraries and build tooling replaced, and tests added so the next change is safer.

Not sure which one fits? Describe what you have and where it needs to go.
